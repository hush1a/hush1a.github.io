# Tech logos

SVG logos for the "Technologies I've worked with" marquee on the homepage
(`src/components/TechMarquee.astro`) that Simple Icons doesn't provide.

Drop a file here named after its key and rebuild; it's picked up automatically:

| Technology       | File name              |
| ---------------- | ---------------------- |
| SQL              | `sql.svg`              |
| VS Code          | `vscode.svg`           |
| Excel            | `excel.svg`            |

Logos are drawn as a silhouette in the text colour, so colour in the file
doesn't matter, but the shape should be a filled glyph on a transparent
background. A file here with the same key as a Simple Icons logo (e.g.
`python.svg`) replaces that logo.
