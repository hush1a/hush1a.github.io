**Back-End Developer** · GarudaHacks 6.0 (Sustainability track)

- Built the backend for a B2B marketplace that connects individuals and businesses with recyclers, turning fashion waste into resources.
- Designed the TypeScript API on Express and TypeORM, backed by PostgreSQL and Redis, in a layered structure of routes, controllers, services and models.
- Implemented the full authentication flow across nine endpoints: registration, login, token refresh, switching between user and business modes, profile, password reset, email verification and logout, secured with JWT, bcrypt, Helmet and request validation.
- Set up Docker Compose for local PostgreSQL and Redis, seed data, Jest tests and API documentation for the mobile team.
- Worked in a team of 3, also contributing to project management.
